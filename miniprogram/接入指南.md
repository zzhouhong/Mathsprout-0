# 萌芽数学小程序接入指南（个人主体 · 本机后端）

> 目标：把仓库里的 `miniprogram/` 接入你已申请好的**个人主体**微信小程序。
> 后端：本机/局域网跑（offline 模式，无需 API key）。更新时间 2026-08-03。

## 1. 一次性：申请小程序 AppID

1. 登录 [微信公众平台](https://mp.weixin.qq.com)（个人主体账号）
2. 左侧「开发」→「开发管理」→「开发设置」→ 找到 **AppID(小程序ID)**
3. 复制它（形如 `wx1234567890abcdef`）

## 2. 填入 AppID

编辑 `miniprogram/project.config.json`，把 `"appid": "touristappid"` 改成你的 AppID。

## 3. 启动后端（本机）

```bash
cd /Users/cuishiming/.zcode/workspace/default/Mathsprout-0/backend
VISION_PROVIDER=offline .venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

后端必须监听 `0.0.0.0`（不能只 `127.0.0.1`），手机/小程序才能访问。

## 4. 在微信开发者工具里跑起来

1. 打开**微信开发者工具**（[下载](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)）
2. 「导入项目」→ 选择 `miniprogram/` 目录 → 填你的 AppID → 确认
3. **关键**：右上角「详情」→「本地设置」→ 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**
   （这一步是本地测试必须的，因为你的后端是 http://192.168.3.7:8000，不是 https 合法域名）
4. 编译运行即可看到小程序首页（家长绑定页）

## 5. 手机真机调试（同一 Wi-Fi）

1. 手机和电脑连**同一个 Wi-Fi**
2. 确认电脑防火墙放行 8000 端口
3. 微信开发者工具 →「预览」，用微信扫码打开
4. 在手机上，`app.js` 里的 `API_BASE_DEV` 必须是电脑的局域网 IP（已改为 `192.168.3.7`，若变了要同步改）

## 6. 发布前必须做的事（⚠️ 微信强制要求）

个人主体小程序**真机/正式版**里，`wx.request` / `wx.uploadFile` 的域名**必须是 HTTPS 且已备案**：

1. 买一个域名 + SSL 证书（个人主体可以备案：ICP 备案）
2. 把后端部署到一台有公网 IP 的服务器，用 Nginx/Caddy 反代到 `https://你的域名/api/v1`
3. 微信公众平台 →「开发」→「开发管理」→「开发设置」→「服务器域名」：
   - **request 合法域名**：`https://你的域名`
   - **uploadFile 合法域名**：`https://你的域名`
4. 把 `miniprogram/app.js` 里 `API_BASE_PROD` 改为 `https://你的域名/api/v1`，`isProd` 改为 `true`
5. 重新上传代码 → 提交审核 → 发布

## 8. 常见问题

- **真机连不上**：确认手机和电脑同 Wi-Fi；电脑防火墙放行 8000；`API_BASE_DEV` 用电脑 IP 而非 localhost
- **上传图片报「request:fail」**：开发者工具没勾「不校验合法域名」，或后端没监听 0.0.0.0
- **发布后报「不在合法域名列表」**：没在公众平台配置服务器域名，或域名没备案/不是 HTTPS
- **分析结果为 offline 假数据**：这是预期——`VISION_PROVIDER=offline` 会读预存 golden case。要真实 AI 识别，见 `docs/VISION_PROVIDER.md` 切 qwen/claude
